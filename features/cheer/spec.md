결정과 미결은 이 파일에만 적는다. 홈 화면 안에서의 위치는 [홈 spec](../home/spec.md)을 따르고, 응원에 관한 결정은 이 파일이 원천이다.

## 목적

지금 서비스는 선수의 솔랭을 알려주기만 한다. 선수 개인 팬이 "내 선수가 지금 뛰고 있다"를 알고도 할 수 있는 일이 없다. 솔랭 카드에서 응원 버튼을 눌러 이 판의 응원 수를 올리고, 팬들의 화력을 숫자로 보여준다. 솔랭 카드가 커뮤니티에서 반응을 얻었으니, 같은 자리에서 한 번 더 참여할 거리를 준다.

응원 수는 누적해서 선수·팬 랭킹으로 이어진다. 누르고 끝나지 않고, 다시 열어볼 이유를 만든다.

## 사용자 흐름

1. 구독 선수가 솔랭 중이면 홈 솔랭 카드 하단에 이 판 응원 수와 `응원하기` 버튼이 붙어 있다.
2. `응원하기`를 누르면 이 판 응원 수와 내가 보탠 수(`+N`)가 바로 올라간다. 누르고 있으면 연타된다.
3. 카드 맨 아래 줄(`응원 랭킹` / `내 순위 N위`)을 누르면 응원 랭킹 화면이 그 선수로 거른 팬 랭킹으로 열린다.
4. 응원 랭킹에는 선수 랭킹과 팬 랭킹 탭이 있다. 둘 다 기간(오늘 / 이번 주 / 이번 달)과 선수 필터를 가진다.
5. 선수 랭킹의 행을 누르면 그 선수의 팬 랭킹으로 간다.
6. 팬 랭킹의 행을 누르면 그 팬이 어떤 선수를 얼마나 응원했는지 시트로 보인다.
7. 판이 끝나면 카드의 응원 영역은 사라지고, 끝난 경기 칩에 그 판의 응원 합계만 남는다.

## 화면 목록

| 화면 | 진입점 | 비고 |
|---|---|---|
| 홈 솔랭 카드의 응원 영역 | 구독 선수가 솔랭 중일 때 | 카드 하단에 이어 붙는다. 스와이프하는 카드마다 자기 선수의 응원 수와 버튼이 있다 |
| 응원 랭킹 — 선수 | 카드의 응원 랭킹 줄, 탭 | 모든 선수가 기본. 기간 토글 + 선수 필터 칩 |
| 응원 랭킹 — 팬 | 카드의 응원 랭킹 줄(그 선수로 거른 상태), 선수 랭킹의 행, 탭 | 전체 팬이 기본. 기간 토글 + 선수 필터 칩. 내 순위는 하단에 고정 |
| 선수 필터 시트(선수 랭킹) | 선수 랭킹의 필터 칩 | 모든 선수 · 내 구독 선수만 / 팀별 / 포지션별. 하나만 고른다 |
| 선수 필터 시트(팬 랭킹) | 팬 랭킹의 필터 칩 | 모든 선수 · 내 구독 선수만 / 검색 + 내 구독 선수·전체 선수(팀별). 알림함의 선수 필터와 같은 방식이다 |
| 팬 응원 기록 시트 | 팬 랭킹의 행 | 응원한 선수 상위 5명을 많이 누른 순으로 보여준다. 내 행은 "내 응원 기록" |

## 상태

| 화면 | 빈 상태 | 로딩 | 에러 |
|---|---|---|---|
| 응원 영역 | 솔랭 중인 선수가 없으면 카드 자체가 없어서 응원 영역도 없다 | 안 그림 | 안 그림. 전송이 실패해도 숫자는 먼저 올리고 나중에 맞출지 미결 |
| 선수 랭킹 | 필터에 맞는 선수가 없으면 "조건에 맞는 선수가 없어요" | 안 그림 | 안 그림 |
| 팬 랭킹 | 아직 응원한 적 없으면 내 순위 자리에 "아직 응원한 적 없어요 · 첫 응원으로 순위에 올라요" | 안 그림 | 안 그림 |
| 선수 필터 시트 | 검색 결과가 없으면 "검색 결과가 없어요" | 안 그림 | 안 그림 |

## 필요한 API · 데이터

백엔드 코드를 `응원`·`cheer`로 찾았으나 이 기능과 관련된 것이 없다(검색에 걸린 것은 라이브 액티비티 푸시 등 무관한 코드). 응원은 전부 새로 만든다.

| 데이터 | 엔드포인트 | 있음 / 새로 / 확인 필요 |
|---|---|---|
| 선수 사진·팀·팀 로고 | `/api/players/cards`의 `playerImageUrl`·`teamCode`·`teamImageUrl` | 있음 |
| 구독 선수 목록 | 구독 API | 확인 필요 (홈 spec의 구독 선수 흐름을 따른다) |
| 솔랭 중 선수, 경과 시간, 챔피언 | 홈 솔랭 DTO | [홈 spec](../home/spec.md)에서 새로 만드는 솔랭 상태 필드(`gameStartTime`·챔피언)를 따른다 |
| 응원 전송 | 새 엔드포인트 | 새로. 선수 하나에 N번을 묶어 보낸다(아래 미결) |
| 선수별 이 판 응원 합계 | 홈 솔랭 DTO에 필드 추가 | 새로. 솔랭 폴링에 같이 실어 홈 응답을 늘리지 않는다 |
| 선수 랭킹 | 새 엔드포인트 (기간, 필터) | 새로 |
| 팬 랭킹 | 새 엔드포인트 (기간, 선수 필터) | 새로. 내 순위를 같이 준다 |
| 구독 선수별 내 순위 | 팬 랭킹의 `내 구독 선수만` | 새로. 선수당 한 행 |
| 팬 응원 기록(선수별 누적) | 새 엔드포인트 | 새로. 팬 한 명의 선수별 누적을 상위 5명까지 준다 |

랭킹 응답 예시(팬 랭킹, 필터 없음). 값은 지어낸 것이다.

```json
{
  "period": "week",
  "playerId": null,
  "fans": [
    { "rank": 1, "nickname": "예시팬1", "count": 4000 }
  ],
  "me": { "rank": 128, "count": 412 }
}
```

## 결정

- 2026-10-09 (창하) **응원 영역은 솔랭 카드 하단에 이어 붙인다.** 솔랭 카드는 선수가 지금 뛸 때만 뜨고, 응원도 그때만 의미가 있다. 이미 반응을 얻은 자리라 새 섹션보다 첫 화면에서 잘 보인다. 사진 위에 반투명으로 얹는 안은 선수 사진 하단을 가려서 1차에서 뺐다.
- 2026-10-09 (창하) **화력 게이지와 콤보는 없다.** 응원 수 숫자가 이미 화력이다. 빠르게 누르면 카드 테두리가 달아오르는 것만 남긴다.
- 2026-10-09 (창하) **내가 보탠 수는 큰 숫자 옆에 `+N`으로 작게 보인다.** `내`라는 글자는 붙이지 않는다. 가운뎃점, 알약 테두리는 어색해서 뺐다.
- 2026-10-09 (창하) **랭킹 진입은 카드 맨 아래 줄이다.** 왼쪽 `응원 랭킹`, 오른쪽 `내 순위 N위 ›`. 작은 글자 링크나 알약 버튼은 눌러야 하는 곳이라는 표시가 약하거나 응원 버튼과 높이가 안 맞았다.
- 2026-10-09 (창하) **기간은 오늘 / 이번 주 / 이번 달이다.** 선수 랭킹과 팬 랭킹이 같다. 전체 누적만 두면 먼저 시작한 소수가 계속 1위라 신규 유저가 의욕을 잃는다.
- 2026-10-09 (창하) **두 랭킹 모두 전체가 기본이고 위에서 선수 필터로 거른다.** 초반에는 팬이 선수별로 흩어져 있어서 선수별로 쪼개면 목록이 비어 보인다. 선수 랭킹의 포지션 칩은 없앴고, 포지션은 필터 시트 안에 둔다.
- 2026-10-09 (창하) **팬 랭킹의 `내 구독 선수만`은 팬을 합치지 않고 선수 단위 행으로 보여준다.** 행마다 그 선수 팬 중 내 순위와 내 응원 횟수를 보이고, 누르면 그 선수의 팬 랭킹으로 간다.
- 2026-10-09 (창하) **팬 행을 누르면 응원한 선수 상위 5명을 시트로 보인다.** 누적 응원 횟수가 팬의 성격을 말해 준다. 필터를 걸어 둬도 시트에는 그 팬의 전체 응원 대상이 나온다.
- 2026-10-09 (창하) **선수 필터는 칩 하나와 시트다.** 선수 칩을 나열하면 구독이 많거나 선수가 늘 때 깨진다. 앱 알림함의 선수 필터가 이미 같은 방식이다.

## 미결

- **어뷰징 상한.** 계정당 초당 몇 번까지 받을지, 서버가 1초 단위로 묶어 합산할지. 매크로 부풀리기를 막고 DB 쓰기도 줄이려면 필요하다.
- **응원 대상 공개 설정.** 팬 행을 누르면 응원한 선수가 보이는데, 공개 여부를 사용자가 끌 수 있게 할지. 목업에는 설정 화면이 없다.
- **기간 경계.** 오늘은 KST 자정 기준인지, 이번 주는 월요일 시작인지.
- **전송 실패.** 숫자를 먼저 올리고 나중에 서버 값에 맞출지, 실패하면 되돌릴지.
- **구독하지 않은 선수.** 랭킹에서 구독하지 않은 선수를 열 수 있는데, 그 선수에게 응원 버튼은 어디서 누르는지. 지금 목업은 솔랭 카드에서만 응원한다.
- **판이 끝난 뒤.** 끝난 경기 칩의 응원 합계는 그 판 합계인데, 칩을 눌렀을 때 어디로 가는지.
- **선수 한글 활동명.** 목업은 영문 이름(Faker)이다. 홈 spec의 한글 활동명 추가와 같이 정한다.
- **후속 아이디어.** 솔랭 시작 푸시에서 바로 응원으로 들어오기, 경기 후 응원 결산 카드 공유, 누적 응원 돌파 알림, 응원 한마디 프리셋, 연속 응원 기록과 칭호. 이번 범위에는 넣지 않았다.

## 목업의 한계

- **실데이터**: 선수 사진, 팀 로고, 선수의 팀과 포지션(2026-10-09 기준), 챔피언 스플래시.
- **지어낸 값**: 응원 수, 랭킹 수치, 내 순위, 팬 닉네임, 팬이 응원한 선수 비율. 서버에 응원 기능이 없어서 전부 예시다. 팬 닉네임은 실유저가 아니다.
- 다른 팬의 응원은 목업이 흉내 낸다(숫자가 저절로 오른다).
- 구독 27명, 솔랭 중 선수 2명, 끝난 경기 4명은 [홈 목업](../home/mockup.html)의 예시 상태를 따랐다.
- 하단 네비와 오늘 경기·순위표는 그리지 않았다. 홈 목업을 본다.
- 기준 폭 375px 한 폭만 봤다.

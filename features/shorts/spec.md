결정과 미결은 이 파일에만 적는다. 홈 화면 안에서의 위치는 [홈 spec](../home/spec.md)을 따르고, 쇼츠에 관한 결정은 이 파일이 원천이다.

## 목적

지금 쇼츠 카드를 누르면 유튜브 앱으로 나간다. 나간 사람은 앱으로 잘 돌아오지 않아서, 쇼츠가 재방문이 아니라 이탈 통로가 된다. 앱 안에서 세로로 넘겨 보게 해서 체류 시간과 재방문을 늘린다.

소스도 바꾼다. 유튜버 채널 쇼츠는 불펌이 많고 싫어하는 사람이 있다는 문의가 왔다. 10개 팀과 LCK가 직접 올린 쇼츠만 쓴다.

## 사용자 흐름

1. 홈 콘텐츠 섹션에서 "쇼츠" 탭을 고른다. 전체 / 내 팀 필터가 있고, 최신 쇼츠 10개가 가로 카드로 보인다.
2. 카드를 누르면 전체화면 플레이어가 열리고, 누른 영상부터 재생된다.
3. 위로 스와이프하면 다음 영상이 나온다. 끝에 가까워지면 다음 20개를 미리 불러온다.
4. 플레이어 위쪽 탭으로 전체 / 내 팀을 바꾼다. 바꾸면 피드가 처음부터 다시 시작한다.
5. 영상 아래의 "유튜브에서 보기"는 원본을 유튜브에서 여는 출구다. 눈에 띄지 않게 둔다.
6. 닫으면 홈으로 돌아온다. 홈 스크롤 위치는 그대로다.

|---|---|---|

## 상태

| 화면 | 빈 상태 | 로딩 | 에러 |
|---|---|---|---|
| 홈 쇼츠 | 내 팀 쇼츠가 0건이면 점선 박스 + "전체 보기". 응원팀이 없으면 "응원팀 설정하기" | 안 그림 | 안 그림 |
| 플레이어 | 홈과 같은 빈 상태 | 안 그림 | 임베드 불가·삭제 영상은 토스트를 띄우고 자동으로 다음으로 넘긴다. 연속 3건 이상 실패하면 "재생할 수 없어요" + "유튜브에서 열기". 다음 페이지를 못 불러와도 현재 영상은 유지하고 "다시 시도"만 보여준다 |
| 플레이어 피드 끝 | "다 봤어요" + "전체 보기" · "커뮤니티 구경하기" | | |

## 필요한 API · 데이터

| 데이터 | 엔드포인트 | 있음 / 새로 / 확인 필요 |
|---|---|---|
| 쇼츠 목록 | `GET /api/story/videos?category=shorts&sort=latest&page=&size=` | 있음. `category`는 all\|pro\|shorts, `sort`는 latest\|views\|likes, `period`는 all\|week\|month. **`category=shorts`가 지금은 유튜버 채널 쇼츠를 준다.** 팀·LCK 공식 쇼츠만 주도록 [nar-back-repo#544](https://github.com/NAR-GG/nar-back-repo/pull/544)가 바꾼다(머지 전) |
| 응답의 팀 코드 | 위 응답의 `teamCode` | 새로. 지금 응답에는 팀 필드가 없어서 앱이 `title + channelName`을 문자열로 대조한다 |
| 내 팀 필터 | 위 엔드포인트의 `teamCode` 쿼리 | 새로 |
| `size` 상한 | 위 엔드포인트 | 새로. 지금은 상한이 없다(200도 통과한다). 기본 20, 상한 50을 제안한다 |
| 내 응원팀 | 앱의 마이페이지 응원팀 값 | 확인 필요. 커뮤니티 작성자의 `teamCode`와 같은 코드 체계인지 |
| 재생 | 유튜브 IFrame 임베드 | 새로(앱). 서버 API가 아니다. 유튜브 Data API 쿼터를 쓰지 않는다 |

**왜 팀 코드를 서버가 줘야 하나.** 채널명을 팀 코드·팀명과 대조하는 지금 방식은 10개 팀 중 4개를 놓친다(표준 팀명·코드 기준 추정).

| 채널명 | 팀 코드 · 팀명 | 문자열 대조 |
|---|---|---|
| Hanwha Life Esports | HLE · 한화생명e스포츠 | 실패 |
| DRX | KRX · KIWOOM DRX | 실패 |
| 브리온 | BRO · 한진 브리온 | 실패 |
| DN SOOPers LoL | DNS · DN 수퍼스 | 실패 |
| T1 · kt Rolster · NS RedForce · Dplus Kia · 젠지 이스포츠 Gen.G Esports · BNK 피어엑스 | T1 · KT · NS · DK · GEN · BFX | 성공 |

**새로 필요한 응답과 요청 예시**

```
GET /api/story/videos?category=shorts&teamCode=GEN&page=0&size=20
```
```json
{
  "youtubeVideoId": "9xAlNOmn4Lk",
  "title": "기인이 귀여워",
  "videoUrl": "https://www.youtube.com/shorts/9xAlNOmn4Lk",
  "channelType": "PRO_TEAMS",
  "channelName": "젠지 이스포츠 Gen.G Esports",
  "teamCode": "GEN",
  "viewCount": 61440,
  "publishedAt": "2026-09-26T19:10:18"
}
```

LCK 공식 채널은 팀이 아니라서 `teamCode`가 `null`이다. 그래서 "전체"에만 나오고 "내 팀"에는 나오지 않는다.

## 결정

- 2026-09-30 (창하) **쇼츠 소스는 10개 팀 공식 채널과 LCK 공식 채널의 쇼츠만 쓴다.** 유튜버 채널(롤뻔뻔·대유쾌마운틴·롤꺾마)은 모든 카테고리에서 뺀다. 근거: 불펌이 많고 싫어하는 사람이 있다는 문의. 데이터는 지우지 않고 숨기기만 한다(#544).
- 2026-09-30 (창하) **"내 선수" 필터를 없앤다. 필터는 전체 / 내 팀이다.** 근거: 공식 채널 영상에는 선수 식별자가 없고, 지금은 제목에서 영문 이름을 문자열로 찾아서 정확도를 보장할 수 없다. (이전: 2026-09-20~21 홍비, "전체"는 내 선수와 내 팀의 합집합이고 정렬은 내 선수 → 내 팀 → 나머지 순)
- 2026-09-30 (창하) **소리는 항상 끈 채로 재생한다.** 처음부터 무음으로 시작한다. 모바일 웹뷰가 소리 있는 자동재생을 막는 경우가 있어 실기기 확인이 필요했는데, 무음 고정이면 그 확인이 필요 없어진다.
- 2026-09-30 (창하) **앱 안에서 재생한다.** 유튜브 공식 IFrame 임베드를 쓴다. 근거: 유튜브로 나가면 재방문이 끊긴다. 임베드는 약관상 허용되지만 플레이어 위에 오버레이를 올릴 수 없다([홈 spec](../home/spec.md) 2026-09-05 조사). 그래서 정보는 플레이어 바깥에 둔다.

## 미결

리뷰에서 정할 것이다. 제안이 있는 항목은 제안을 함께 적었다.

| # | 질문 | 제안과 근거 |
|---|---|---|
| 1 | 홈 카드는 몇 개, 피드는 어떻게 이어가나 | 홈은 10개 미리보기, 피드는 최신순 20개씩 무한 스크롤. "며칠치" 창은 쓰지 않는다. 최근 7일은 17건, 5일은 6건, 3일은 1건이라 경기 없는 날 비어 버린다(2026-09-30 실측). 누적은 팀 10개만 769건이라 20개씩 봐도 한동안 끊기지 않는다 |
| 2 | "전체"의 정렬 | 순수 최신순. 내 팀 우선 정렬은 시간 순서를 깬다 |
| 3 | "내 팀"의 기준 | 마이페이지 응원팀. 지금 앱은 구독 선수들의 소속팀 합집합인데, 선수 개념을 걷어내면 근거가 사라진다 |
| 4 | LCK 영상을 "내 팀"에 넣나 | 넣지 않는다. 팀 영상이 아니다 |
| 5 | 소리 해제 방법 | 앱에 별도 해제 버튼을 두지 않는다. 유튜브 임베드에 자체 소리 컨트롤이 있어서 그걸로 충분하다. 해제한 상태가 다음 영상에서도 유지되는지는 실기기 확인이 필요하다 |
| 6 | 영상이 끝나면 | 자동으로 다음 영상으로 넘긴다 |
| 7 | 임베드 불가 영상 | v1은 앱에서 스킵한다. 최근 쇼츠 150건 중 2건(1.3%)이 임베드 불가·삭제였다. 스킵이 잦으면 서버가 `embeddable`을 저장해서 미리 거른다 |
| 8 | 세로 썸네일 | `oardefault.jpg`(1080×1920)를 먼저 쓰고 없으면 서버가 준 `thumbnailUrl`로 폴백한다. 최근 150건 중 113건(75%)에만 있다 |
| 9 | 앱 출시 방식 | IFrame 플레이어는 네이티브 플러그인이라 Shorebird 패치로 못 나가고 스토어 릴리스가 필요하다. "내 선수" 제거와 서버 필터 연동은 Dart 코드라 패치로 먼저 나갈 수 있다 |
| 10 | 쇼츠가 없는 팀 | Dplus Kia는 5월 중순, DN SOOPers는 8월 하순이 마지막 쇼츠다. 내 팀이 이 팀이면 빈 상태를 보게 된다. 비어 있을 때 "전체 보기"만 두면 충분한지 |
| 11 | 지표 | 홈 쇼츠 노출 → 카드 탭률, 플레이어 진입 → 재생 시작률, 세션당 시청 개수, 임베드 오류율, "유튜브에서 보기" 탭 수, 피드를 본 유저의 D1·D7 재방문 |
| 12 | 실기기 확인 | 유튜브 임베드가 Referer를 요구해 오류 153이 나는 사례가 보고돼 있다(미검증). iOS·Android에서 뜨는지, 세로 스와이프에서 WebView가 몇 개까지 버티는지 |

## 이 목업의 한계

- 쇼츠 제목·조회수·팀은 prod 실데이터다. 10개 팀은 prod `/api/story/videos`로, LCK는 채널 탭에서 가져왔다. 2026-09-30 시점의 스냅샷이다. 유튜브 영상은 재생하지 않고 썸네일로 대체했다.
- 팀 로고는 `/api/standings?league=LCK`의 이미지 URL을 그대로 쓴다.
- 내 응원팀(T1·KT·DK)은 예시다. 스위치로 바꿔서 빈 상태와 미설정 상태를 볼 수 있다.
- 동작하는 것은 필터, 카드 탭, ▲▼·방향키·휠 넘기기, 응원팀 스위치뿐이다. 스와이프 제스처와 닫기는 그림이다. 오른쪽 위 소리 꺼짐 아이콘은 상태 표시일 뿐이다.
- 유튜브 재생 컨트롤(진행 바 등)은 임베드 안에 있어서 앱이 그리지 않는다. 목업의 얇은 진행선은 그 자리를 표시한 것이다.
- 로딩 상태는 안 그렸다. 375px 한 폭에서만 확인했다.
